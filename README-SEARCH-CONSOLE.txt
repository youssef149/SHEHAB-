اسم الموقع: يوسف شهاب

قبل نشر الموقع:
1) افتح Google Search Console وأضف الموقع كـ URL-prefix property باستخدام رابط موقعك الحقيقي.
2) اختر HTML tag كطريقة التحقق.
3) انسخ meta tag الذي تعطيه Google وضعه مكان السطر الموجود في index.html:
<meta name="google-site-verification" content="YOUR_GOOGLE_VERIFICATION_CODE">
4) انشر index.html ثم اضغط Verify.

ملاحظة: اسم property في Search Console مرتبط بالموقع/الرابط الذي تضيفه، وليس بقيمة يمكن للكود اختيارها. اسم يوسف شهاب هنا مضبوط كعنوان الموقع وبيانات SEO.
